# Harsh Recruiter Scoring Rubric & Benchmark Standards

This rubric defines the exact standards applied by the Harsh Recruiter Subagent when evaluating internship resumes.

---

## The 4 Pillars of Evaluation

### Pillar 1: Quantified Impact & The Google XYZ Formula (40 Points)
Every bullet point must adhere to the formula:
> **Accomplished [X] as measured by [Y] by doing [Z]**

- **Level 4 (35-40 pts)**: All bullets have clear metrics (latency reduction, QPS, data volume, percentage gains with baseline scale, user count, or benchmark comparisons).
- **Level 3 (25-34 pts)**: Most bullets have numbers, but 1-2 lack business or engineering significance.
- **Level 2 (15-24 pts)**: Generic accomplishments with vague metrics ("improved speed", "built responsive app").
- **Level 1 (0-14 pts)**: Passive job descriptions ("Responsible for writing code and attending standups").

### Pillar 2: Technical Rigor & Engineering Depth (35 Points)
- **High Signal**: Concurrency, distributed consensus, memory management, profiling/benchmarking, custom network protocols, fault tolerance, containerization, CI/CD pipelines.
- **Medium Signal**: Standard CRUD applications, full-stack web apps with authentication, REST APIs, basic database schemas.
- **Low Signal / Red Flag**: Boilerplate tutorial clones (to-do lists, weather apps, simple calculator, generic portfolio).

### Pillar 3: Brevity, Density & Fluff Demolition (25 Points)
- **Strict 1-Page Rule**: Resumes for university/internship applicants must be exactly 1 page.
- **Fluff Elimination**: Zero filler adjectives ("passionate", "motivated", "detail-oriented", "synergized").
- **No Orphan Lines**: Avoid wrapping a sentence onto a new line for only 1 or 2 trailing words.
